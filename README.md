# نظام إصدار وإدارة فواتير المبيعات - شركة الوفاء للمستلزمات
### Al-Wafaa Medical Supplies & Cosmetic - Receipt & Admin System

نظام متكامل واحترافي لإصدار فواتير المبيعات وإدارتها مبني باستخدام **React + Vite**، ومصمم ليلائم كافة الشاشات (Desktop & Mobile) مع ميزة تصدير الفواتير إلى ملفات **PDF عالية الجودة (300 DPI)** مع معالجة وترابط كامل للخطوط العربية.

---

## 🌟 المميزات الرئيسية (Key Features)

### 1. صفحة الفاتورة (Receipt & Invoice Generator)
- **مطابقة 100% للتصميم المطلوب**: ترويسة شركة الوفاء للمستلزمات، جدول بنود الفاتورة باللون الذهبي الدافئ، صفوف الفاتورة المنقطة، ملخص الحسابات، وقسم الملاحظات وبيانات التواصل.
- **المدخلات اليدوية (Manual Inputs)**:
  - اسم العميل (`اسم العميل`)
  - الكمية لكل صنف (`الكمية`)
  - السعر لكل صنف (`السعر`)
  - الضريبة (`الضريبة`)
- **الحسابات والتوليد التلقائي (Automated Features)**:
  - تاريخ اليوم الحالي تلقائياً (`التاريخ`)
  - التسمية الترتيبية التلقائية للأصناف باللغة العربية: *الصنف الأول، الصنف الثاني، الصنف الثالث...* (`البيان`)
  - الإجمالي الفرعي لكل بند: $\text{الكمية} \times \text{السعر}$ (`الاجمالي`)
  - إجمالي السعر التلقائي (`اجمالي السعر`)
  - الإجمالي العام الشامل للضريبة (`الإجمالي العام`)
  - إضافة وحذف الأصناف بسهولة
- **التصدير والطباعة (Export & Print)**:
  - **تحميل PDF**: تصدير الفاتورة مباشرة بمقاس A4 بدقة فائقة وبخطوط عربية متصلة وسليمة 100%.
  - **طباعة الفاتورة**: مجهزة للطباعة المباشرة بأبعاد ورقة A4.
  - **اعتماد الفاتورة (Submit)**: حفظ الفاتورة مع تأثير احتفالي ونافذة منبثقة تفاعلية بالملخص.

### 2. لوحة الإدارة (Admin Dashboard)
- عنوان ثنائي الألوان مطابق للشعار: `Al-Wafaa Medical Supplies and Cosmetic`.
- بطاقات إحصائيات فورية: `عدد العملاء` و `الاجمالي العام لجميع العملاء`.
- بحث فوري لحظي في الفواتير وأسماء العملاء (`البحث عن عملاء او فواتير`).
- جدول الفواتير مع شارات العملاء الملونة (`NP`, `PC`, `BV`) وأرقام الفواتير والمبالغ بالريال السعودي (`SAR`).
- زر تفاعلي `View →` لفتح أي فاتورة من لوحة الإدارة في صفحة الفاتورة مباشرة للطباعة أو التنزيل.
- ترقيم وتصفح الصفحات (`Pagination`).

### 3. التوافق التام مع الجوال (Mobile Responsive)
- نظام تحجيم ذكي لورقة الفاتورة لتلائم عرض شاشات الهواتف دون الحاجة إلى التمرير العرضي.
- شريط تبديل علوي للتنقل بين وضع الإدخال والمعاينة على الجوال.
- شريط إجراءات سفلي عائم وثابت لسهولة الاعتماد والتصدير.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **React 19**
- **Vite**
- **html-to-image & jsPDF** (لتصدير الـ PDF عالي الدقة بدون تقطيع الخط العربي)
- **Lucide React** (أيقونات عصرية)
- **Canvas Confetti** (تأثيرات الاعتماد التفاعلية)
- **Google Fonts (Cairo & Tajawal)**

## 🚀 طريقة التشغيل (Getting Started)

1. استنساخ المستودع:
```bash
git clone https://github.com/meselhy2003-svg/-receipt-system.git
cd -receipt-system
```

2. تثبيت الحزم:
```bash
npm install
```

3. تشغيل خادم التطوير:
```bash
npm run dev
```

4. فتح المتصفح على:
`http://localhost:5173/`

5. لبناء نسخة الإنتاج:
```bash
npm run build
```
